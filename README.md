# Zoom Dialer Companion

Windows desktop companion for Zoom Phone. Plays prerecorded clips or local TTS into an active call by mixing microphone audio through a virtual microphone (VB-CABLE). Does not modify Zoom Phone or use undocumented Zoom APIs.
